# TrainGuard

TrainGuard is a mobile-first endurance training risk app.

It imports activities from Strava, lets the user complete quick recovery and pain check-ins, and generates simple training status alerts.

## Tech Stack

- Mobile: React Native / Expo
- Backend: Spring Boot / Java
- Database: PostgreSQL
- Container: Docker
- Testing: JUnit, Mockito, Spring Boot Test
